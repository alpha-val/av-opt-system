# Alpha‑Val Backend (Minimal Scaffold)

This is the *minimal* code scaffolding. Files are mostly empty so you can grow the app organically.

## Quick start
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn src.app.main:app --reload
```
Open http://127.0.0.1:8000/docs
